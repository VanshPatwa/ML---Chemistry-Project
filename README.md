# ML---Chemistry-Project
This project implements a lightweight machine learning workflow designed to estimate the aqueous solubility ($LogS$) of organic compounds using physical descriptors from the Delaney (ESOL) dataset. The pipeline processes 1,128 organic molecules using six core chemical features: Minimum Degree, Molecular Weight, Number of H-Bond Donors, Number of Rings, Number of Rotatable Bonds, and Polar Surface Area. The repository includes the processed dataset (delaney-processed.csv), a Jupyter notebook detailing model training and evaluation (solubility_predictor.ipynb), presentation slides (solubility prediction using machine learning.pptx), and a serialized package (solubility_model_package.joblib) containing both the fitted Scikit-Learn preprocessing pipeline and the final model.To run predictions without retraining, load the serialized package using joblib and pass a formatted DataFrame containing the six required features to the pipeline.
